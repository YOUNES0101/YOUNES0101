## About

I focus on how infrastructure is built, connected, and defended — from configuring and hardening a Linux host to segmenting networks, automating deployments, and investigating suspicious activity.

My work sits at the intersection of **Linux, networking, infrastructure automation, and cybersecurity**. I learn by building realistic labs, breaking them on purpose, analysing the failures, and documenting the results. Understanding *why* a system behaves the way it does matters more to me than simply getting a tool to run.

```yaml
focus:     [Linux, Networking, Infrastructure Automation, Cybersecurity]
building:  SAIP — Secure Autonomous Infrastructure Platform
approach:  build → test → investigate → document
```

### 🛡️ SAIP
**Secure Autonomous Infrastructure Platform**

<img src="https://img.shields.io/badge/Status-In%20progress-F5A623?style=flat-square" alt="Status: in progress"/>

- **Observability** — metrics, logs, and SIEM alerting
- **Validation** — controlled failure and attack simulations

### 🔥 Firewall Security
**Java-based packet filtering application**

<a href="https://github.com/YOUNES0101/Firewall-Security"><img src="https://img.shields.io/badge/View%20repository-58A6FF?style=flat-square&logo=github&logoColor=white" alt="Firewall Security repository"/></a>

A desktop application that captures live traffic, applies configurable filtering rules, and displays allowed and blocked packets in real time.

- **Capture** — live packet capture with Pcap4J
- **Rules** — extensible rule engine (Strategy pattern)
- **Filtering** — by IP, port, protocol, and packet size
- **History** — traffic logs stored in MySQL
- **Persistence** — Hibernate / JPA, containerised with Docker

`Java 21` `JavaFX` `Pcap4J` `Hibernate` `MySQL` `Docker`
