# Hey, I'm Younes 👋

I enjoy understanding how systems work beneath the surface — how networks communicate, how infrastructure is built, how security controls protect it, and how automation makes everything more reliable.

Most of my time goes into hands-on experiments, building technical projects, exploring Linux and networking, and figuring out why things break and how to fix them.

I believe the best way to learn technology is to build with it, test its limits, and understand what happens behind the scenes.

## What I'm interested in

- **Infrastructure & Virtualization** — Linux systems, Proxmox, networking, and building isolated environments.
- **Network Security** — firewalls, traffic filtering, network segmentation, and secure system configuration.
- **Automation & DevOps** — Terraform, Ansible, Docker, and repeatable infrastructure deployments.
- **Monitoring & Security Operations** — logs, metrics, SIEM, threat detection, and automated response.
- **Software Development** — building practical tools that solve problems and connect theory with real-world use.
